---

With this mod, No More Heroes Paradise is now what I would consider to be best version of No More Heroes, an no longer held back by stupid decisions that nearly ruined the game.

This mod features TONS of QOL adjustments, not only giving it parity with the PC version, but far exceeding it. In my opinion, this is the definitive way to experience No More Heroes.

This mod does not rebalance, or change the core of the game at all, it just migrates the all of PC improvements to it, removes motion controls, restores cut content and music, and reverts all the other negative changes while still retaining the awesome exclusive features that this version has that you can only find on the PS3 version.

## What's Changed?

### 60FPS Support

* The original 30FPS cap has been removed, allowing the game to run at 60FPS for much smoother gameplay.

### Mandatory Motion Controls COMPLETELY REMOVED

* Sword recharging is now done by shaking the right analog stick (like the PC version) versus shaking the controller.
* Minigames that previously required motion controls now use appropriate analog stick movements instead.

### Original OST Restored

* Heavenly Star has been restored as the shop music.
* Heavenly Star has also been restored to the game's cutscenes. When the song was originally removed on PS3 some cutscenes were left with dialogue only. These now all have their original music back.

### Unnecessary Button Inputs Removed

* R3 no longer needs to be pressed before performing a killing blow. You're now directly prompted to move the analog stick in the direction of the slash (like the PC version).
* R3 and L3 no longer need to be pressed before performing wrestling moves. You're now directly prompted to move the analog sticks (like the PC version).

### Other QOL Improvements

* **Improved colors:** The PS3 version originally had an extremely high gamma multiplier applied to its textures, resulting in blown-out contrast. Colors have been adjusted to look closer to the original Wii version and especially the Xbox 360 version, which looks best.
* **Sword Clashes:** You can now rotate either the left or right analog stick during sword clashes.
* **Updated button prompts:** The old motion gesture sprites have been replaced with appropriate analog stick graphics.

## Why the PS3 Version?

Because aside from everything fixed above, the PS3 version already has a TON of improvements over the Wii, PC, and Switch versions that often get overlooked, that make a lot of fun and superior in many ways.

Here's what's exclusive to or improved in the PS3 version:

### Combat

* Store Dark Side buffs for later use (excluding boss fights).
* Ability to move while charging both types of charge attacks.
* Wrestling move names are called out when activated.
* Double roulette when killing multiple enemies with a single blow.

### Missions & Additional Content

* Teleport directly to missions after completing them once.
* Retry failed missions without having to restart the entire mission.
* Score Attack Mode, a dedicated boss battle mode that also features NMH2 bosses.
* 5 additional minigames.
* 5 additional Hit Missions.
* Mission replay, boss replay, and cutscene replay.

### Open World & General Improvements

* Bring up the map at any time using L1.
* View the map while riding your bike.
* The map is easier to read thanks to the removal of the pixelation filter.
* The mostly empty hub map world has been reduced in size, making events and travel more compact and higher fidelity for the events on it. The original open world was mostly empty, so shorter traversal is a plus with events now happening closer to each other with more activity in a more focused area.
* Pick up collectibles without getting off your bike.
* New music added
